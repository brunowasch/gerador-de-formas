# Gerador de Formas

O ShapeDraw é uma aplicação desktop desenvolvida em Java utilizando Swing para a criação e visualização de formas geométricas bidimensionais e tridimensionais.

A aplicação permite adicionar círculos, quadrados, triângulos, esferas, cubos e tetraedros em posições aleatórias, com dimensões e cores geradas automaticamente. As formas são organizadas em ordem crescente de área e podem ser removidas utilizando o botão de limpeza.

O projeto utiliza conceitos de Programação Orientada a Objetos, como herança, abstração e polimorfismo, além de coleções com `ArrayList`, ordenação com `Comparable` e recursos gráficos das bibliotecas Java Swing e AWT.

## Tecnologias

Java, Java Swing e Java AWT.

## Execução

Para executar a aplicação, clone o repositório, abra o projeto em uma IDE Java e execute a classe `App.java`. É necessário ter o JDK instalado e configurado.

## Objetivo acadêmico

Projeto desenvolvido como atividade acadêmica para praticar conceitos de Programação Orientada a Objetos e desenvolvimento de interfaces gráficas em Java.
